.. _gui:

Graphical user interface (GUI)
==============================

To launch the Linguistica GUI:

.. code-block:: bash

    linguistica gui

To read an input file, go to **File**, then:

* **Select the Brown corpus** to use the bundled Brown corpus directly; or
* **Select CMUDICT** to use the bundled CMU pronouncing dictionary (a wordlist)
  directly; or
* **Select corpus...** for a corpus text file of your own; or
* **Select wordlist...** for a wordlist file of your own.

As soon as an input file is selected, it is loaded and run automatically.

Once an input file has been loaded, you may change any parameters by going to
**Parameters...** under **File**. (This menu item is disabled until a file is
loaded.) For what the parameters are and their default values,
see :ref:`parameters`.
